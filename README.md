# Stock Dashboard (Public)

Public dashboard source, separately maintained from the private Cloudflare deployment.

## Data pipeline (public edition)

The pages are static and read local JSON files (for example `data.json`,
`sectors.json`, `semiconductors.json`). Those JSON files are generated by the
scripts in `scripts/` and refreshed automatically by GitHub Actions
(`.github/workflows/public-data.yml`, weekdays after the US and Japan market
closes). You can also run any script locally:

```bash
python3 scripts/update_data.py            # -> data.json (market overview)
python3 scripts/update_sectors.py         # -> sectors.json
python3 scripts/update_jp_sectors.py      # -> jp-sectors.json
python3 scripts/update_semiconductors.py  # -> semiconductors.json
python3 scripts/update_us_semiconductors.py
python3 scripts/update_sector_leaders.py  # -> sector-leaders.json (screener)
```

Public, key-less sources only:

- Stock prices and index history: Yahoo Finance unofficial chart API
  (`query1`/`query2.finance.yahoo.com/v8/finance/chart/...`)
- JP listed universe: JPX official listed-shares spreadsheet (`data_j.xlsx`)
- US universe lists: public S&P 500 constituents / ticker CSVs on GitHub
- SOXX news headlines: Yahoo Finance RSS (summaries machine-translated)
- JP semi summaries: Kabutan market-news articles

Not included in the public edition (private deployment only): moomoo and
SimFin feeds, private EPS datasets, API keys, and Cloudflare deployment
configuration. JP market-breadth rows in `data.json` stay empty unless
`ALLOW_TSE_THIRD_PARTY_DATA=true` is set after confirming permission to use
that third-party source. The backtest pages under `backtest/` still require
their own intraday data files under `backtest/data/`.

Yahoo Finance data is unofficial and may be delayed or changed without
notice; do not rely on it as a sole source for trading decisions.
