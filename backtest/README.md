# 株価戦略研究所 — 太陽誘電1分足

独立したGitHub Pages用プロジェクト。太陽誘電 `6976.T` の1分足を時系列順で再生し、最大20取引日を使用し、20日未満でも暫定バックテストできます。2日以上は古い半分で条件を選び、新しい半分で期間外検証します（20日の場合は10日＋10日）。エリオット波動等の既存理論を前提とせず、価格・出来高・時間帯の条件を比較します。

## GitHub上の構成と使い方

このリポジトリは `GRW1107s/stock-backtest` です。公開URLはGitHub Pagesが有効になった後、https://grw1107s.github.io/stock-backtest/ になります。

1. GitHubの `Settings > Pages > Build and deployment` で Source を `GitHub Actions` に設定してください。リポジトリは公開設定です。
2. `Actions > Taiyo Yuden 1-minute backtest and Pages > Run workflow` から再実行できます。平日16:50 JSTにも自動で1分足を収集します。
3. 20取引日未満でも暫定バックテストできます。データが1日だけの場合は同一期間内の検証結果のみで、期間外検証ではありません。取得したYahoo Financeの1分足は7日程度の制限があるため、20日分の即時検証には過去1分足CSVの投入が必要です。
4. 1分足CSVをサイトからアップロードできます。CSVはローカルブラウザで処理され、GitHubにはアップロードされません。

## 売買シミュレーション

- 対象: 太陽誘電のみ、買い→売り（空売りは実装しない）
- 1〜20取引日分の実1分足を使います。部分データも一場60本以上あれば暫定対象として使い、欠損区間は補完せず、連続足が途切れた場所ではシグナルを出しません。全日相当と部分データは区別して表示します。
- 過去から最新へ時系列再生。2〜20取引日なら古い `ceil(N/2)` 日で各パターンの条件を選び、残りの新しい日でパラメータを固定して検証。1日しかない場合は同じ日を用いた探索的成績として表示し、期間外検証と呼びません。
- シグナル判定関数に渡るデータは「その時点で確定済みの1分足」だけ。次足の始値でエントリー。
- 事前に定めた利確・損切りで手仕舞い。両方が1分足に収まったら損切り先行（保守的）。指定保有時間を経過したら次足始値で決済。
- 連続した前場または後場内のみで売買。昼休み・夜間をまたがない。重複売買はない。
- 往復コストの初期値0.10%。手数料・スプレッド・スリッページの合計を概算控除。実際の取引では約定価格の差が生じる。
- 価格・出来高だけの6パターン×複数パラメータ・利確損切り・保有時間で約54条件。学習期間に最低 `min(5, 学習取引日数)` 件の売買がないパターンは未評価。短期間の成績は統計的に不安定です。
- 勝率、平均損益、合計損益、最大ドローダウン、取引履歴CSVを表示。

## データの限界

Yahoo Financeの非公式Chart APIは通常1分足を直近約7日しか提供しません。初期アーカイブに過去20取引日分の実データは含まれていません。**20日未満でも暫定的に勝率を計算しますが、少数日・少数取引では信頼できる優位性の証拠ではありません。**

TradingViewでエクスポートしたCSV（`time,open,high,low,close,volume`）にも対応しています。time は Unix秒・ミリ秒、JST時刻、タイムゾーン付きISO日時のいずれかです。実際の約定量、板の厚み、部分約定、配当・株式分割等は考慮していません。検証結果は投資判断の保証ではありません。

GitHub Pagesで公開したリポジトリは第三者にも閲覧可能になり得ます。データの提供元の再配布規約も確認してください。
## 20営業日の過去1分足を入れる方法
- Yahooの1分足は取得可能な遡及期間が短いため、現在のGitHubアーカイブだけで20営業日になるとは限りません。
- J-Quants「株価 分足・ティック」アドオン契約のある場合、太陽誘電 6976 の1分足を取得してCSVとして保存し、サイト内の読み込み欄に選択してください。標準的な `Date,Time,Code,O,H,L,C,Vo` 形式を直接解釈します。
- 有料データの契約条件を確認し、公開リポジトリへ直接アップロードせず、ご自身のブラウザ内で読み込んでください。
- 過去20取引日未満でもバックテストできます。1日だけなら学習期間内、2日以上なら時系列で分離した期間外検証の暫定結果を表示します。

## x%下落で買い・y%上昇で売る3日反復学習

- 公開ページ: https://grw1107s.github.io/stock-backtest/episode.html
- 直近の1分足30本の最高値から `x%` 下落した瞬間に買いシグナルを発生させ、次の1分足始値で買う。買値から `y%` 上昇したら利確する。損切りは一律 `-0.8%`、25分保有か場の終了で手仕舞い。
- 下落率 `x` と利確率 `y` は3取引日を1エピソードとして繰り返す探索で更新する。取引ごとの正解ラベルや未来の足は使わず、エピソード末尾の総合得点だけで選択する。
- 得点: 売買コスト控除後の取引損益率の単純合計 − 最大ドローダウン絶対値の0.5倍（売買0件なら -0.9点）。
- 初期値 `x=0.60%`、`y=0.50%`。探索範囲 `x=0.15〜3.0%`、`y=0.10〜2.0%`。学習の継続、履歴表示、パラメータJSON保存が可能。
- 学習した同じ3日の利益は、期間内成績であって予測精度ではない。新しい取引日の価格データが追加されたら、その日の結果を学習パラメータ固定で確認する。
- このアプリはユーザーのブラウザ内で学習し、パラメータと得点履歴はブラウザのローカル保存領域に保存する。GitHub側のCIでも初期30回の試行例を再現して公開する。
